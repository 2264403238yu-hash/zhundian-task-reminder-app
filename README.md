# 准点 · 任务提醒

一个不依赖服务器和账号的离线任务提醒 PWA。可安装到手机桌面，任务数据只保存在当前设备的浏览器中。

## 已实现功能

- 添加、编辑、完成、恢复和删除任务
- 截止日期、时间、优先级、分类、备注
- 准时提醒，或提前 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 3 小时 / 1 天提醒
- 浏览器系统通知、应用内弹窗、提醒音
- Android 通知震动与页面内振动提醒
- “稍后 10 分钟”与撤销删除
- 每天 / 每周 / 每月重复任务
- 今日进度、逾期统计、任务搜索和分类筛选
- 一键接入系统日历、Google 日历或生成 `.ics` 文件，获得可靠闹钟提醒
- 深色模式、通知权限设置、后台检查
- JSON 数据导入 / 导出，离线缓存，安装到手机桌面

## 部署到手机

这是一个纯静态 PWA。云端选一种方式即可：

### 方式一：Netlify Drop（最简单）

1. 在电脑打开 [Netlify Drop](https://app.netlify.com/drop)。
2. 解压拿到的 `zhundian-task-reminder.zip`。
3. 把解压后的整个文件夹拖到 Netlify Drop 页面。
4. 等待生成 `https://...netlify.app` 地址。
5. 用手机浏览器打开该地址。

### 方式二：GitHub Pages

1. 新建一个 GitHub 仓库。
2. 把本文件夹内的所有文件上传到仓库根目录。
3. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`，分支选择 `main` / `root`。
4. 打开 GitHub Pages 提供的 HTTPS 地址。

## 安装到桌面

### Android / Chrome

1. 用 Chrome 打开部署后的网址。
2. 点右上角菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 打开应用，在“设置 → 通知与声音”中允许通知。

### iPhone / Safari

1. 用 Safari 打开部署后的网址。
2. 点底部分享按钮。
3. 选择“添加到主屏幕”。
4. 打开应用，在设置中允许通知。

> iPhone 必须使用 Safari 添加。微信内置浏览器、部分安卓浏览器不支持完整 PWA 安装能力。

## 提醒可靠性说明

- 应用打开或刚刚回到前台时，提醒最准确。
- Android 安装为 PWA 后，可尝试“设置 → 后台提醒 → 启用后台检查”。系统会按省电策略定期检查，但不能保证精确到分钟。
- Android 支持时，应用会尝试使用系统定时通知；后台网页检查仍可能受省电策略影响，不能保证精确到分钟。
- iPhone 对后台网页通知限制较严格。最可靠的跨平台做法是：任务卡片中点击“加入日历”，选择用系统日历打开并保存。系统日历会负责到点提醒，即使应用完全关闭，并跟随手机设置使用震动。
- 浏览器通知必须运行在 `https://` 地址上；本机测试地址 `http://localhost` 除外。
- 清理浏览器数据、卸载浏览器或更换手机会删除本地任务，建议定期在“设置 → 数据与应用 → 导出备份”。

## 本机预览

在项目目录运行：

```powershell
python -m http.server 8080
```

然后电脑访问 `http://localhost:8080`。手机要获得可安装、可通知的体验，建议部署到 HTTPS 静态托管。
